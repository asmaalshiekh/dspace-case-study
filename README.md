# دراسة حالة: تصميم وتطوير مستودع جامعة طيبة الرقمي (DSpace Repository)

> **الدور:** محلل ومسؤول أنظمة (Systems Analyst & Administrator)  
> **المدة:** فترة إنجاز مكثفة (دورة حياة المشروع الكاملة من الصفر للإنتاج)  
> **الأدوات:** DSpace 6.3, PostgreSQL, Apache Tomcat 8, OpenJDK 8, Maven, Ant, UI/UX Customization, Draw.io

---

## 1. الملخص التنفيذي
تنفيذ وإدارة ودورة حياة كاملة لنشر وتخصيص مستودع رقمي مؤسسي متكامل لجامعة طيبة. تم بناء النظام بمعايير قياسية عالمية لهندسة المعارف والمستندات الرقمية (مثل Dublin Core)، مع تخصيص شامل للواجهات، التعريب الكامل، وهيكلة الأقسام والكليات بدقة عالية.

---

## 2. التحديات التقنية (Situation & Challenge)
- **قيود البنية التحتية والصلاحيات:** التعامل مع تحديات التثبيت وإغلاق بعض الصلاحيات، ومعالجة أخطاء توافقية بيئات التشغيل (Java, Maven, Tomcat, PostgreSQL).
- **ندرة المصادر العربية وتخصيص الأكواد:** تجاوز أخطاء الـ Build والـ Compilation البرمجية عبر التحليل المنطقي والاستعانة بالذكاء الاصطناعي كمساعد تقني.
- **التخصيص المؤسسي المتقدم:** الحاجة لتعريب النظام بالكامل، بناء قوائم منسدلة مخصصة، وربط مستودعات الأصول الرقمية (كتب، فيديوهات، رسائل علمية) بهيكل تنظيمي ضخم.

---

## 3. الحل والممارسات المنفذة (Task & Action)

### أ. تخطيط البنية التحتية ومتطلبات السيرفر (Infrastructure & Server Provisioning)
بصفتي مسؤولة الأنظمة، قمت بتحديد وهندسة متطلبات بيئة التشغيل والخوادم بدقة لضمان استقرار النظام المؤسسي:
- **مواصفات السيرفر والبيئات:** تخصيص بيئات العمل (Test, Development, Production) وتحديد مواصفات المعالج (CPU)، الذاكرة العشوائية (RAM = 8 GB)، وتقسيم وحدات التخزين (الأقراص C, D, E بسعات تصل إلى 550GB).
- **إدارة الأمان وصلاحيات الوصول (Access Control):** ضبط عناوين الـ IP الخاصة بالمسؤولين (مثل `10.56.180.34` و `10.56.180.31`)، وتحديد أنواع الاتصال الآمن (RDP / SSH) والمنافذ المطلوبة لتشغيل وصيانة النظام.

### ب. هندسة المعلومات والهيكل التنظيمي (Information Architecture)
تم تصميم هيكل شجري تنظيمي دقيق للمستودع يخدم آلاف المستفيدين، شمل:
- **المجتمعات الرئيسية (Top Communities):** مستودع الجامعة الرقمي ومصادر المعلومات بالجامعة.
- **المجتمعات الفرعية (Sub-Communities):** تمثيل كافة كليات الجامعة (علوم الحاسب، الهندسة، الطب، العلوم الطبية، إدارة الأعمال، وغيرها) وتفريعاتها الأقسام الأكاديمية الدقيقة.

### ج. التخصيص البرمجي والتعريب (UI & Localization Customization)
- **التعريب الكامل:** تعريب واجهات النظام بالكامل وخصائص البحث ودعم محارف اللغات المختلفة.
- **التصميم البصري (Branding):** إضافة البنر الرسمي للجامعة وتخصيص القوائم المنسدلة للوصول السريع للأقسام والمحتويات (فيديو، كتب إلكترونية، منشورات علمية).
- **إدارة الصلاحيات والأمان:** إنشاء مجموعات المستخدمين (Communities/Collections Policies) وضبط سياسات الإيداع والاستعراض والتحكم بصلاحيات الإشراف والنشر.

### د. البنية التقنية والتشغيل (Technical Setup)
- **البيئة:** Ubuntu 18.04.1 LTS, Apache Tomcat 8, PostgreSQL (مع تفعيل `pgcrypto`)، و Maven/Ant.
- **إدارة الأصول:** رفع وتجربة عينات حقيقية لمصادر معلومات متعددة الصيغ (PDF, Webm Videos) واختبار محرك الاسترجاع والبحث الذكي.

## 5. النتائج والأثر (Results)
- **إطلاق ناجح بنسبة 100%:** استقرار تشغيلي تام للنظام ودخوله حيز الخدمة الفعلية.
- **كفاءة تنظيم المعارف:** توفير بيئة رقمية موحدة تخدم الباحثين وأعضاء هيئة التدريس والطلاب لاسترجاع الأبحاث والرسائل العلمية بأعلى دقة وسرعة.
